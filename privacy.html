Les détails

Le texte complet, pour ceux qui veulent tout lire.

Ce que nous gardons, et pourquoi
  • Votre numéro de téléphone : pour vous envoyer un code de connexion par WhatsApp.
  • Votre nom : le nom que vous voulez afficher dans l'application.
  • Votre adresse email, si vous la donnez : pour récupérer votre compte si vous perdez votre numéro ou changez de téléphone.
  • Les infos de votre boutique : produits, ventes, crédits, dépenses, clients, fournisseurs et équipe, pour que vous les retrouviez sur tous vos téléphones.
  • Le fonctionnement de l'app : modèle de téléphone et rapports d'erreur, pour corriger les bugs.

Nous ne les utilisons jamais pour vous montrer de la publicité.

Où sont vos données

Vos données sont d'abord dans votre téléphone. Quand il retrouve internet, une copie est envoyée dans notre base de données, pour que vous les retrouviez sur tous vos téléphones.

Cette base de données est hébergée par Supabase, sur Amazon Web Services, aux États-Unis (région Ouest des États-Unis 1, Californie du Nord).

Quand vous supprimez votre compte, vos données sont aussi effacées de cette base de données.

Qui chez Patron peut voir vos données

Vos données sont stockées sur nos serveurs. L'équipe Patron peut donc techniquement y accéder. Nous le faisons seulement :

  • quand vous nous demandez de l'aide, pour regarder le problème avec vous ;
  • pour réparer un bug qui touche votre boutique.

Pour suivre la santé de Patron, nous regardons des totaux (nombre de boutiques, nombre de ventes enregistrées), jamais le détail d'une boutique.

Votre code de connexion

Nous envoyons votre code par WhatsApp. WhatsApp reçoit donc votre numéro pour livrer le message. Nous n'utilisons jamais le SMS.

Alpha, l'assistant

Quand vous posez une question à Alpha, nous utilisons les chiffres de votre boutique (ventes, stock, dépenses) uniquement pour vous répondre. Jamais pour la publicité, jamais revendus.

Sans internet

Patron marche sans internet. Ce que vous écrivez reste chiffré dans votre téléphone, et l'app remet tout à jour dès que la connexion revient.

Si vous perdez votre téléphone, nous ne pouvons retrouver que ce qui a déjà été envoyé à notre serveur. Ce qui a été écrit sans internet et pas encore envoyé ne peut pas être récupéré.

Supprimer votre compte

Dans l'app : Plus → Paramètres → Supprimer mon compte. Votre compte est effacé définitivement après 30 jours. Si vous vous reconnectez avant, la suppression est annulée.

Si une autre boutique doit garder une vente que vous avez faite pour elle, votre nom y est remplacé par « Compte supprimé ».

Vos droits
  • Voir : toutes vos ventes et tout votre argent sont dans l'application.
  • Changer : le nom de votre boutique, vos prix, vos produits, quand vous voulez.
  • Effacer : supprimez votre compte depuis l'application.

Pour une demande que l'app ne permet pas encore, écrivez-nous.
